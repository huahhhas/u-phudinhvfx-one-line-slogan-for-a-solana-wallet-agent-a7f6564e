# One-Line Slogan for a Solana Wallet Agent

A single original slogan for a Solana wallet agent, written by a small Python program. The wallet agent does the chores — paying, swapping, saving — while you get on with living.

> Your Solana wallet agent handles the paying, the swapping, the saving — you handle the living.

## Run it

```sh
python3 main.py
```

This writes the slogan to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). The line is a single line, 94 characters, 16 words — inside the 1–140 character, 20-word gate.
